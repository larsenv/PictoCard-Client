## What's new

- **One download for every console.** The Wii, Wii U and 3DS apps now live in one repository, with one release that has all three. The old PictoCard-Wii, PictoCard-WiiU and PictoCard-3DS repositories are gone.
- **Wii: USB mouse.** The mouse moves the pointer, the left button selects, the right goes back, the middle opens Review and the wheel scrolls, in every screen and in the keyboard.
- **Wii: update check.** PictoCard looks for a newer release when it starts and offers to install it.
- **Wii: the system keyboard.** Short fields open a keyboard that looks and sounds like the Wii's own. Long messages still use the built-in one.
- Smaller download: the Wii app is now a compressed `boot.dol`.

## Install

Extract the zip for your console to the root of your SD card (Wii also: or USB drive) and open PictoCard from the Homebrew Channel (Wii), the Wii U Menu (Wii U, needs Aroma) or the Homebrew Launcher (3DS).
