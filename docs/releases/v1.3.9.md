## What's new

- **Faster on every console.** The app now reuses its secure session with the server instead of setting one up from scratch for every request, so live previews, Mii faces and sending no longer each wait for a full handshake.
- **Exit asks first.** With a card in progress, the exit button (HOME on Wii and Wii U) asks you to press it again instead of throwing the card away. Nothing changes when there is nothing to lose.
- **Buttons no longer do nothing while the app is busy.** Send, Add PictoCard to this Wii and the verification code used to be ignored while a live preview or Mii faces were loading. They now wait their turn behind the progress box.
- **Fixed: the live preview sometimes did not appear.** A preview that arrived at the wrong moment could be dropped, leaving the old card on screen until the next edit.
- **Email typos are caught at once.** An address such as `name@example` is reported when you review the card, not after the anti-spam check and upload.
- **Update notice.** The "newer version available" notice compares version numbers properly (1.10 is newer than 1.9) and points to pictocard.net/app.
- **Hardening.** A malformed server answer can no longer make the app copy memory out of bounds, an over-long server address is refused, and the app stops instead of spinning forever if it is ever handed an impossible anti-spam check.

## Install

Extract the zip for your console to the root of your SD card (Wii also: or USB drive) and open PictoCard from the Homebrew Channel (Wii), the Wii U Menu (Wii U, needs Aroma), the Homebrew Menu (Switch) or the Homebrew Launcher (3DS).
